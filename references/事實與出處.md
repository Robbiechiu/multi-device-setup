# 事實與出處

> 查證日期 2026-11-17，對照 Claude Code v2.1.322。官方文件會更新，與使用者畫面不符時以畫面為準。

## 遙控（Remote Control）
來源：https://code.claude.com/docs/en/remote-control

- 手機（Claude App，iOS／Android）或瀏覽器（claude.ai/code）連到**你電腦上正在跑的** Claude Code session。
- 啟動：`claude --remote-control`（或 `--rc`）；已開著的 session 裡打 `/remote-control`（或 `/rc`）；也可以用 `claude remote-control` 開伺服器模式。
- 畫面會給網址和 QR code，掃 QR code 會在 Claude App 打開。App 裡點 **Code**，電腦圖示加綠點＝在線上。
- **電腦要開著，`claude` 程式要一直跑**；關掉終端機或 Claude 就離線。
- 電腦睡著或斷網，恢復後會自動接回（一般模式會一直重試；伺服器模式約 10 分鐘後放棄並結束）。
- 執行與檔案存取都留在你的電腦上；但連線期間，**對話紀錄會存在 Anthropic 的伺服器**。
- 方案：Pro、Max、Ultra、Team、Enterprise 可用；API key 不行；Team／Enterprise 要管理員先打開。
- 一般模式下，一個 Claude 程式同時只能有一個遙控 session。
- 部分指令（如 `/plugin`、`/resume`）只能在電腦上用。
- 官方頁**沒有列出作業系統限制**（Windows 能不能用未寫明，需實測）。
- 自動開啟設定：`~/.claude/settings.json` 的 `"remoteControlAtStartup": true`（設定名稱已在 v2.1.322 執行檔中確認存在）。

## 雲端 session（Claude Code on the web）
來源：https://code.claude.com/docs/en/claude-code-on-the-web 、https://code.claude.com/docs/en/cloud-environments

- 跑在 Anthropic 管理的雲端，每個 session 是一台全新的虛擬機。筆電關了也會繼續跑，可從任何裝置（含 Claude App 的 Code 分頁）查看。
- 從 **GitHub 專案**複製一份開工；建立 PR 也需要 GitHub。其他平台（GitLab 等）只能打包上傳，做完推不回去。官方文件**沒有提到 Google Drive** 當工作來源。
- 做完的改動會推到 GitHub 的分支；可在 claude.ai/code 開 PR，或在電腦上用 `claude --teleport` 把 session 接回終端機（分支必須已推上去）。
- 從終端機只能「雲端 → 本機」單向接回；Desktop App 可以把本機 session 送上雲端。
- **會帶過去**：專案裡的 `CLAUDE.md`、`.claude/skills/`、`.claude/agents/`、`.claude/commands/`、專案的 `.mcp.json`。
- **不會帶過去**：你電腦上的 `~/.claude/CLAUDE.md`、`~/.claude/skills/` 等個人設定。官方建議：要用就 commit 進專案的 `.claude/`。
- 在 session 上開啟的連接器（connectors）可以使用。
- 網路預設是「Limited」（只允許套件庫、GitHub 等），可改。
- 閒置一段時間會暫停；之後虛擬機會被回收，對話紀錄保留，還在跑的背景工作不會保留。
- 環境變數用 `.env` 格式設定，**同一環境的人都讀得到**；API key 建議用 network secret。

## 經驗法則（非官方文件）
- 不要把 GitHub 專案放進 Google Drive 的同步資料夾：兩套同步工具會搶著改同一批檔案，容易產生「檔名 2」「(1)」這類重複副本（羅伯特實際遇過）。
- 公司配的電腦屬於公司，不建議存私人密碼、金鑰、機密檔。
