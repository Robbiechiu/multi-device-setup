# 多裝置設定 skill

羅伯特 AI 學院學員用。讓 Claude 問你幾個問題，幫你規劃並設定「人不在電腦前也能用 Claude Code」：家裡電腦、公司電腦、手機怎麼分工，資料該放哪裡。

## 安裝（跟 Claude 說這句就好）

> 幫我安裝這個 skill：https://github.com/Robbiechiu/multi-device-setup ，裝到 ~/.claude/skills/multi-device-setup

Claude 會執行：

```bash
git clone https://github.com/Robbiechiu/multi-device-setup.git ~/.claude/skills/multi-device-setup
```

## 使用

裝好後重開 Claude Code，跟它說：

> 幫我做多裝置設定

## 更新

不用自己更新。每次使用時，skill 會先自動把自己更新到最新版。

完整說明頁：https://cc-class.pages.dev/qa/remote-devices
